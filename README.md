# IDPortfolio

## Project Overview
IDPortfolio is a personal portfolio mobile application developed to present personal information, skills, projects, and background.

## Main Features
- Home screen
- My Profile
- Edit Profile
- Save and cancel profile changes
- My Skills
- My Projects
- Project Details
- About Me
- Navigation between screens
- Profile data persistence

## Technologies Used
- React Native
- Expo
- TypeScript
- React Navigation
- AsyncStorage

## Requirements
- Node.js and npm
- Expo development tools

## Installation and Running
1. Clone or download this repository.
2. Open the project folder in a terminal.
3. Install dependencies:

   npm install

4. Start the application:

   npx expo start

5. Follow the Expo instructions to open the application on a supported device or browser.

## Project Purpose
The application demonstrates mobile application development, screen navigation, profile editing, local data persistence, and project presentation.
